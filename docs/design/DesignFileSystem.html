How it works

insert(path, isFile):
  split path by "/"  → ["", "a", "b", "file.txt"]
  walk children, create missing nodes
  mark last node as file/dir

search(path):
  split path by "/"
  walk children, return null if missing
  return final node

ls(path):
  node = search(path)
  if node.isFile → return [node.name]
  else → return keys of node.children

addContentToFile(path, content):
  node = insert(path, isFile=true)
  node.content.append(content)
